# LAB 8 – User Information Form

## Project Overview
This project is a simple web application designed to collect user information using HTML form elements and JavaScript.

The application captures user details such as name, gender, mobile number, email address, city, state, and country. After submitting the form, the entered information is displayed on a separate web page.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Features
- User-friendly registration form.
- Input fields for personal information.
- Gender selection using radio buttons.
- Email and mobile number validation.
- Reset button to clear entered information.
- Continue button to submit user details.
- Displays submitted information on another page.

## How It Works
1. Open the User Information Form.
2. Enter your name, gender, mobile number, email ID, city, state, and country.
3. Click the Continue button.
4. JavaScript stores the entered information using Local Storage.
5. The application redirects to the display page.
6. All submitted user information is displayed.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Fill in the required information.
5. Click Continue to view the submitted details.
